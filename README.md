# Gestor de Tareas (To-Do List)
Un sencillo gestor de tareas escrito en Python, diseñado para ejecutarse en la terminal.

## Características
- **Modular:** Lógica separada de la interfaz.
- **Persistente:** Guarda tus tareas en un archivo `data.json`.
- **Fácil de usar:** Menú interactivo sencillo.

## Cómo ejecutarlo
1. Asegúrate de tener Python instalado.
2. Clona este repositorio o descarga los archivos.
3. Ejecuta el comando: `python main.py`
